# 09 — Admin weapon-model uploads

`/admin` is a private page, served by the game server itself, for uploading `.glb` weapon models. It adds no new server and nothing to the game bundle.

Uploads are only **stored**. They are never served to players and never added to the game automatically. The workflow is:

1. Open `https://game-hub.joura.info/admin` and sign in.
2. Find the gun, give the model a name, and drop the `.glb` on that gun's card (up to 100 MB). Use **Preview** to check it looks right.
3. Tell Claude. It copies the files from the server, checks them, optimises them, tests how they look in the Gunsmith and in a match, adds them to the repo, and deploys.

## Password

The page is disabled (every `/admin` route returns 404) until `ADMIN_PASSWORD` is set. The password lives in a `.env` file next to `docker-compose.yml`, which is git-ignored so it never reaches the repo:

- On the VPS: `/opt/game-hub/.env`
- On the dev machine: `.env` in the project root (used if you run the stack locally)

To change it, edit the `ADMIN_PASSWORD=` line in the VPS `.env` and run `docker compose up -d`. Wrong passwords lock an address out for 10 minutes after 10 attempts.

## Where files are stored

In the `ratings` Docker volume under `/data/uploads/`, so redeploying does not delete them. Each upload is `<id>.glb` plus a small `<id>.json` (gun, name, original filename, size, date).

```bash
docker compose exec server ls -lh /data/uploads
# copy everything to the current folder:
docker compose cp server:/data/uploads ./uploads
```

## Limits and checks

- Only binary glTF 2.0 (`.glb`). The file header and declared length are checked, so renamed files are refused.
- 100 MB maximum. Host nginx (`deploy/host-nginx.conf`) and the web container (`deploy/nginx.conf`) both allow 100 MB for the upload route only, and stream the upload without buffering it.
- At most 12 uploads per minute. File names are generated by the server, never taken from the upload.

## Local development

```bash
ADMIN_PASSWORD=demo pnpm dev:server    # then open http://localhost:2567/admin
```

Uploads go to `./uploads` unless `ADMIN_UPLOAD_DIR` is set.
